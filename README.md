# SongIQ — Guess the Song & Music Quiz Game

The ultimate African music trivia game. Test your music IQ across Afrobeats, Amapiano, Highlife, Bongo Flava & more.

## Features

- 🎵 Solo music quiz — guess the song or artist
- 👥 Real-time multiplayer — challenge friends in live quizzes
- 🌍 8+ African music genres
- 🏆 Leaderboards & scoring

## Getting Started

```bash
npm install
npm run dev
```

## Tech Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS
- Framer Motion
